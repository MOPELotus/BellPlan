# 功能与验证清单

目标桌面平台为 Windows 10/11。当前版本已实现主要节目管理、调度和播放流程，仍有未实现功能和实机验证项。

“已实现”表示存在对应逻辑；“单元测试覆盖”表示测试了指定规则或调用，不等于 Windows 实机播放通过。以下记录产品功能、当前实现和验证范围。

## 功能矩阵

| 编号 | 功能 | 当前实现 | 验证证据与剩余事项 |
| --- | --- | --- | --- |
| 01 | 多节目单、编辑、作息表切换 | 已实现节目单增删改、启停与筛选；SQLite 持久化 | `test_core.py`、`test_backend.py` 覆盖归属、启停、删除约束；GUI 检查创建、删除。重启后的完整操作仍需 Windows 验收 |
| 02 | 节目增删改、启停、上下移动、名称／时间正反排序 | 已实现，增加复制与搜索；不设固定节目数量上限 | 核心测试覆盖大量节目、稳定顺序及节目单隔离；GUI 检查创建、修改、删除、搜索。超大数据量性能尚未定标 |
| 03 | 文件／目录、顺序／随机、独立音量 | 已实现文件与递归目录扫描、去重、随机、节目音量 | `test_playback.py` 覆盖路径与列表逻辑；Windows 真实媒体、声道和音量待验收 |
| 04 | 多开始时间、去重、清空、按分钟批量生成 | 已实现时间列表、秒精度与批量生成入口 | 核心测试覆盖多时点；批量生成的边界与小数分钟间隔需进一步 GUI 验证 |
| 05 | 每周／每月重复 | 已实现每周、每月与指定日期；设置每月日期时优先使用每月规则，不受星期选择限制 | `test_core.py` 覆盖周末的每月日期、指定日期优先级及调休；Windows 实际跨日运行待验收 |
| 06 | 日期有效范围、一次性 | 已实现起止日期、秒级起止日期时间、指定日期和排除日期，可限定某天 | `test_core.py` 覆盖秒级边界、反向范围拒绝、预览一致性及调休后按实际日期校验；相应编辑流程需 GUI 验证 |

| 08 | 准时抢占、延后排队 | 已实现抢占、队列、优先级与稳定顺序 | 播放及调度测试覆盖抢占、排队和同刻优先级；真实同时到点连续播放待验收 |
| 09 | 全局／节目输出设备、失效回默认 | 已实现设备枚举、选择、默认回退及失败反馈 | 测试覆盖失效设备和无默认设备；Windows 多声卡、热插拔及实际输出路由待验收 |

| 11 | a 日期按 b 日期播放、备注、启停、排序 | 已实现日期映射、备注、启停与列表操作 | 核心测试覆盖目标日期模式、实际日期有效期、禁用映射及禁播限制；复杂日历配置的 GUI 操作仍需验收 |
| 12 | 即时列表导入、删清、排序、乱序、上下移、打开目录 | 已实现持久列表及上述操作中的名称排序；按文件类型排序尚缺 | `test_live.py` 覆盖选择位置、重排、重启保存和失败原子性；真实文件对话框与目录操作待 Windows 验收 |

| 16 | 播放状态、进度、单次终止、日志 | 已实现通道状态、独立停止、运行状态记录、滚动文件日志及打开入口 | 播放测试区分开始／完成／失败／取消；GUI 检查日志页。长时间运行和文件轮转待验证 |

## 已有验证的边界

自动测试覆盖调度规则、存储事务、播放状态逻辑、即时列表、音频清单完整性和 Windows 服务调用。模拟音频端点、模拟播放器及注册表测试不能证明真实声音输出或 Windows 系统操作完成。

Linux 图形检查使用物理 NVIDIA Tesla T10，运行时渲染器记录为 `Tesla T10/PCIe/SSE2`，驱动 `580.178.04`。已完成的六页操作和截图不证明全部设置、所有弹窗、所有屏幕尺寸或后续提交都已验收。

Windows 验证步骤见 [WINDOWS_TESTING.md](WINDOWS_TESTING.md)。资源清单见 [BUNDLED_RESOURCES.md](BUNDLED_RESOURCES.md)，使用说明见 [HELP.md](HELP.md)。未完成项补齐后，仍须进行对应实机验证。
