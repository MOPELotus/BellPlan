# 架构

支持 Windows 10/11。使用 Python 3.10+、PySide6 6.8 / Qt Quick Controls，离线运行。

- `domain.py`：节目和节目单校验、日期与禁播规则。
- `storage.py`：SQLite 持久化、节目管理、事务导入。
- `service.py`：独立调度线程、数据库连接、版本化只读缓存、恢复与时钟变化检查。
- `windows_events.py`：Windows 电源与设备事件观察。
- `selfcheck.py`：非图形便携包与资源完整性检查。
- `scheduler.py`：到期计算、补播窗口、持久去重；不执行系统操作。
- `playback.py`：Qt Multimedia、语音、队列、双通道和设备。
- `commands.py`：外部命令参数解析、状态观察与退出分离；不接管或终止外部程序。
- `live.py`：立即播列表和参数。
- `backup.py`：备份范围筛选、导入预检。
- `resources.py`：音频目录与便携引用。
- `migration.py`：迁移适配器接口。
- `platform_services.py`：Windows 系统服务。
- `backend.py`：界面操作桥接、文件选择、运行日志。
- `app.py`：进程、托盘、渲染设备诊断。
- `qml/`：Qt Quick Controls 桌面界面。

节目和节目单使用动态集合及数据库存储，不设人工数量上限。实际容量取决于硬件和存储。后台默认每 100 毫秒检查到期事件，界面刷新与日志发布不会决定检查频率。检查间隔不等于音频开始精度，运行日志分别记录检测与启动延迟。

同一节目同一计划时刻采用持久去重。执行前崩溃可能留下已认领状态，不自动重播，以免重复执行；日志区分认领、开始、完成、取消和失败。休眠与退出期间不能播放，仅在短补播窗口内补偿。暂停后恢复不会补播暂停期间的任务。

仓库只包含独立编写的应用代码、测试、使用文档及音频资源，不保存原版程序、逆向代码或调查中间材料。旧数据转换当前未实现；迁移适配器与新版 JSON 备份独立设计。
