# 使用说明

目标系统：Windows 10/11。其他系统可运行部分功能；登录自启、系统主音量、锁屏和电源动作以 Windows 实机验证为准。完整状态见 [功能清单](FEATURE_PARITY.md)。

## 创建节目

1. 在“节目单”中创建或选择作息表。
2. 选择“添加节目”，填写名称、开始时间与重复规则。多个开始时间每行填写一个，格式为 `HH:MM:SS`；也可使用批量生成。
3. 选择音频文件、目录或内置音频。目录在播放时递归扫描。
4. 设置结束方式、音量、输出设备及日期范围，保存后启用节目。

结束方式可选列表循环遍数、播放首数或播放秒数。对应限制为 0 时持续播放，直到手动停止；不要把节目数量无固定上限理解为不受内存和存储限制。

“准点播出”会抢占当前定时节目；“排队”会等待当前定时节目结束。相同时间按优先级及稳定顺序处理。手动调整顺序只影响同一节目单。

选择每月日期后，按每月规则执行，不受星期选择限制。仅某天播放可使用“仅指定日期”，并检查起止日期和排除日期。节目有效范围支持日期及精确到秒的起止日期时间。

## 节假日与调休

“节假日与调休”页可以设置命名禁播日期或时段。禁用一条假日记录会保留记录，并停止应用该禁播规则。

调休将实际日期映射到另一日期的节目模式。例如，周六按周一播放，可把周六映射至对应周一。实际日期的有效期和禁播规则仍然生效。备注及启用状态单独保存。

## 立即播

在“立即播”页添加文件或目录，可移动、移除、排序或打乱列表。移除列表项不会删除原音频文件。播放模式包括列表、单曲和随机；结束方式与定时节目分开保存。

即时播与定时播使用独立通道。“停止立即播”保留定时通道；停止全部播放会清空待播队列并停止两路。可定位的媒体支持拖动进度，语音或不支持定位的媒体会给出提示。

设置中的“插播时定时播音量（%）”是保留比例：填 30 表示即时播期间保留定时播原音量的 30%，填 0 表示静音，填 100 表示不压低。即时播结束后恢复。

## 音频与多路输出

节目音量控制本程序的播放；Windows 系统主音量控制当前默认输出端点，两者独立。选择节目输出设备时，可使用系统默认设备，也可指定枚举出的设备。指定设备失效会尝试回默认设备，并记录错误或警告。

外置 USB 声卡可提供额外输出口。需要不同区域播音时，应把声卡输出与对应功放、音箱分区连接，并在节目中选定设备。当前程序具有定时与即时两路通道，不提供任意数量独立区域的并发混音调度；多个输出口也不会自动完成现场分区。

设备选择、热插拔及多声卡路由需在现场测试。扩展名被识别不代表该格式已实际解码验证；CDA 光盘音轨当前未实现。

随程序携带的音频可按分类搜索、试听、加入节目或即时列表，内容以当前音频清单为准。详情见 [内置资源](BUNDLED_RESOURCES.md)。当前离线语音功能为朗读，不提供文字导出 MP3、录音剪辑、响度处理或格式转换工具。

## 托盘、自启与单实例

启用“关闭窗口后继续在托盘运行”后，关闭窗口会隐藏到托盘；系统没有托盘时不会用此方式隐藏。托盘菜单可打开窗口、停止全部播放或退出程序。退出后调度停止。

“登录 Windows 后启动”对应用户登录时启动程序，不是电脑开机或自动登录。换安装路径后应重新核对该设置。Windows 平台检查步骤见 [WINDOWS_TESTING.md](WINDOWS_TESTING.md)。

同一数据目录只允许一个程序实例。再次启动会显示实例已运行提示，可从托盘恢复主窗口。不同 `--data-dir` 使用不同数据库、日志与实例锁；不要让多个实例重复执行同一播音计划。

## 电源与外部设备

关机、重启可创建为按时执行的节目，沿用星期与日期规则。程序在提交动作前显示 60 秒倒计时，可通过“取消系统动作”取消。锁屏入口调用 Windows 的锁屏功能。真实动作与取消流程须在 Windows 环境验证。

定时开机需要主板 BIOS／UEFI 的定时唤醒功能及相应供电条件。本程序没有代替主板设置定时开机，也不能在完全关机后自行运行。

功放开关由功放自身或合适的外部定时插座控制；程序不内置继电器、插座或功放硬件控制。播音时间与外部供电时间应分别设置，留出设备启动时间。

## 数据、备份与日志

“设置”页显示实际数据目录，并提供打开入口。目录中包含 `bellplan.sqlite3` 数据库、相关 SQLite 文件、`activity.log` 和实例锁。正常迁移优先使用导出备份；需要复制整个数据目录时先退出程序，避免复制到写入中的数据库。

导入／导出使用新版 JSON，可选择节目、节假日、调休、即时列表和设置。导入前校验数据；导入的命令与系统动作节目保持禁用，核对后手动启用。导入偏好不会自动修改当前 Windows 登录自启登记。

备份保存音频引用，不复制自选音频。迁移电脑时，自选文件需另行复制并核对路径。内置音频使用可移植引用，从当前安装位置解析。

旧数据迁移接口保留，尚未实现原版数据转换。本阶段使用新版 JSON 备份，不支持旧配置直接导入。

“运行日志”显示最近记录，可打开完整日志文件。文件采用轮转保存，每份约 2 MB，最多保留 4 份轮转文件。执行记录区分到期认领、开始、完成、失败和取消；“认领”不表示已经出声。

程序必须处于运行状态才能播音。默认只补偿最近 30 秒的到期时刻，暂停期间的节目会跳过；长时间关机或休眠后不会补播全部历史节目。同一计划时刻持久去重，崩溃后不会自动重播已经认领的节目。

## 没播或没有声音

先查看日志，确认节目已启用、所属节目单已启用、当前日期和时间规则匹配，且没有被假日或排除日期抑制。再检查路径、输出设备、节目音量、系统音量、静音状态及现场功放连接。试听一段已知可用音频，可以区分调度问题与声音输出问题。

功能范围与待验证事项见功能清单。

外部程序由系统独立运行。退出铃序不会终止已经启动的外部命令；退出后不再跟踪其完成状态，日志会保留说明。
