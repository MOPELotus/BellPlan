声音位于 `src/bellplan/assets/music/`。`assets/manifest.json` 记录每个文件的名称、分类、包内相对路径、大小和 SHA-256。复制时已逐项比较来源与目标哈希；自动测试继续检查内置文件与清单的一致性。资源可以直接在媒体资源页选择，不依赖原安装目录。

音频只在解码后的 PCM 数据完全一致时合并，不按相似文件名删除。原“上课-人声（17s）”与“上课-女童（17s）”内容一致，现保留后者；清单的 `aliases` 保留前者的旧路径，旧绝对路径和旧 `builtin://` 引用会解析到保留文件，媒体列表只显示一次。

备份使用 `builtin://music/分类/文件名.mp3` 引用内置声音，不在备份中重复复制音频。恢复时从当前安装位置解析，因此换电脑或更新安装目录后仍可使用。只有资源清单中的音频可以使用此引用；未知文件和目录遍历引用会被拒绝。用户自行选择的音频路径保持原样，其文件仍需用户一并迁移。

`assets/help/index.html` 是本项目独立编写的本地帮助，不包含原程序界面或帮助文档资料。

音频作为独立资源收录，不声明为本项目原创录音。原程序 EXE、DLL、AX、界面资料、内嵌字体和图片不包含在本项目中；新版 UI 使用独立实现的界面元素。
