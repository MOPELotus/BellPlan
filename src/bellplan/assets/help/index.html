铃序使用帮助

定时播

选择“添加节目”，填写节目名称、所属节目单、开始时间及重复规则。选择音频文件、目录或内置音频，设置结束方式和音量后保存。节目、所属节目单和“启用定时播”都打开时，才会自动执行。

时间可填写多行。指定日期优先于每月日期；填写每月日期时忽略星期；二者都为空时按星期执行。实际日期的有效期和禁播限制始终适用。

立即播

添加文件或目录后选择单曲、列表或随机播放，可调整顺序、播放首数或秒数。立即播使用独立通道，可压低定时播音量，停止后恢复。播放滑条仅用于支持定位的音频。

节假日与调休

节假日设置禁播日期与时段。调休指定某日按另一日期或星期播出，禁用后恢复按实际日期执行。实际日期的有效期与禁播限制仍然适用。

备份

可选择节目单、节假日、调休、立即播列表及设置。备份不复制用户音频；内置音频使用便携引用，用户文件保留原路径。导入会合并数据，命令和系统动作保持禁用，核对后启用。当前支持本项目 JSON 备份，旧版迁移接口保留。

运行与日志

关闭窗口可继续在托盘运行，退出后停止调度。电脑关机、休眠或程序未运行期间不能播放，恢复时仅处理补播窗口内的任务；暂停期间的节目不会在恢复时补播。日志与数据目录可从界面打开。

输出设备

设置默认输出设备，也可单独指定节目设备。指定设备不可用时记录提示并回到默认设备；没有可用设备时播放失败。节目音量和 Windows 系统主音量分别控制。音频格式支持取决于实际解码器与设备。

系统操作与硬件

关机、重启、锁屏及登录自启用于 Windows。关机和重启有 60 秒可取消倒计时。自动开机需要设备固件或系统任务支持；功放定时断电需要相应硬件。多分区广播需要匹配的声卡、线路和功放。
